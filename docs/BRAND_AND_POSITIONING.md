# 芽绘台 / SproutCanvas — 产品定位与品牌规范

- 保留本文命名和图像工作台定位. 以 [当前 PRD](PRD.md) 确定已实施的功能边界.
- 将第 3 章的旧变量名/色值作为品牌取色历史参考; 当前 UI 使用 [设计规范](DESIGN.md) 和 `src/styles/tokens.css`, 不恢复旧样式文件.

## 1. 产品命名

| 项 | 内容 |
|---|---|
| 中文名 | **芽绘台** |
| 英文名 | **SproutCanvas** |
| 工程代号 | `sprout-canvas` (GitHub 仓库名/包名) |

### 1.1 命名释义
- **芽**: 嫩芽 / 萌发 — 隐喻「一句 prompt 萌发出画面」的创作起点; 同时自带嫩绿色彩, 与界面护眼绿调性同源.
- **绘**: 绘画 / 生图 — 直接点题图像生成, 中和「芽」的轻盈感, 让产品有专业气质.
- **台**: 工作台 / workbench — 强调多 Provider 聚合 + 工作流编排的「平台」属性, 与代号一脉相承.
- **SproutCanvas**: Sprout 对应「芽」, Canvas 是图像创作行业通用术语 (Photoshop / InvokeAI Unified Canvas), 表达「可创作的画面空间」.

### 1.2 命名不适用场景
- 不要简称为「芽」或「Sprout」— 单字/单词会丢失专业感, 且 Sprout 容易与 SproutCore (老牌 JS 框架) 混淆.
- 对外正式文案统一用「芽绘台」, 不用「芽绘工坊 / 芽绘工作台」等变体, 保持唯一识别.

## 2. 产品定位

### 2.1 一句话定位
**芽绘台是一个聚焦图像生成的多 Provider 创作工作台.**

### 2.2 范围 (In Scope)
- 文生图: OpenAI Images API 及兼容网关 (Elysiver / abrdns / AnyRouter 等).
- 图生图: 最多 4 张参考图生成, 局部重绘 (蒙版编辑).
- 提示词优化: 独立文本模型润色, 风格库模板, 系列分镜拆解.
- 多服务商管理: 服务端按能力选择通道, 后端代理, API Key 不落前端.
- 作品管理: 输出归档, 参数复用, 下载.

### 2.3 范围外 (Out of Scope)
- **不做视频生成** — 当前阶段视频模型成本和门槛过高, 不纳入产品范围.
- 不做模型训练 / LoRA 训练.
- 不做 Photoshop 级图层编辑.
- 不做团队协作 / 计费 / 多租户 (V2 议题, 暂不启动).

### 2.4 目标用户
- 自己使用 + 小范围分享的图像创作者.
- 需要在多个 API 服务商之间切换比价 / 比效果的进阶用户.
- 看重数据自托管 (API Key 不交给第三方网页) 的隐私敏感用户.

## 3. 视觉品牌规范

### 3.1 调性关键词
**护眼 · 清新 · 自然 · 专业**

低饱和绿调为主, 暖白底打底, 避免高饱和刺眼色; 风格接近「自然光下的纸面 + 嫩叶」, 适合长时间创作.

### 3.2 品牌取色参考

> 产品支持 light / dark 双主题. **浅色主题 (暖纸白) 是品牌基准和默认主题**; 暗色主题为可选辅助.
> 现行变量为 `src/styles/tokens.css` 中的 `--sc-*` 语义色, 通过 Tailwind 语义类使用; 完整表 (含 dark 值) 见 `docs/DESIGN.md` §2. 本节只记录品牌层基准.

| 用途 | 语义角色 | 浅色 | 暗色 | 说明 |
|---|---|---|---|---|
| 品牌叶绿 | `primary-container` | `#597445` | `#597445` | 品牌强调表面 |
| 主操作 | `primary` | `#415B2F` | `#839E6C` | 按钮 / 主行动 / 焦点; 暗色主动降饱和 |
| 纸面底色 | `surface` | `#FAF9F5` | `#171B16` | 暖纸白; 全局底色 |
| 内容卡片 | `surface-container-lowest` | `#FFFFFF` | `#20241E` | 最高层纸面 |
| 输入井 | `surface-container-low` | `#F4F4F0` | `#1C211C` | 输入底 / 次级面板 |
| 正文 | `on-surface` | `#1B1C1A` | `#E8EBE3` | 比纯黑柔和 |
| 说明与轮廓 | `outline` | `#74796D` | `#8A9280` | 次要说明, 轮廓 |
| 错误 | `error` | `#BA1A1A` | `#F2A8A8` | 砖红, 饱和度受控 |

- 成功与信息状态复用主色系, 不另设颜色.
- 投影使用原稿绿灰调与低透明度边框区分纸面层级, 不使用纯黑阴影.

### 3.3 圆角与节奏
- `rounded-2xl` 16px: 大面板 / 模态 / 查看器 / 抽屉.
- `rounded-xl` 12px: 内容卡 / 任务卡 / 风格卡 / 按钮.
- `rounded-lg` 8px: 输入 / 缩略图 / 小控件.
- 胶囊 `rounded-full`: 导航项 / 过滤 pill / toast / 状态徽标.

圆角为中等柔和体系 (8/12/16px), 柔和不幼态; 以 `docs/DESIGN.md` §4 和 `tailwind.config.cjs` 为准.

### 3.4 字体
| 用途 | 字体 |
|---|---|
| 标题 | Outfit |
| 正文 | Inter |
| 元信息/参数 | JetBrains Mono |

字体与图标均为本地 WOFF2, 层级和许可见 `docs/DESIGN.md` §3.

### 3.5 动效
- 控件变化约 150-200ms, 抽屉/弹层约 200-300ms, 体感轻盈.
- 尊重减少动态效果设置, 避免不必要的持续动画; 细则见 `docs/DESIGN.md` §4.

## 4. 命名与视觉的协同
- 「芽」的嫩绿语义 ↔ 品牌叶绿 `primary-container` (#597445) 与灰绿轮廓的低饱和绿系.
- 「绘」的创作动作 ↔ 暖纸白 `surface` (#FAF9F5) 底色, 像在纸上落笔.
- 「台」的工作台属性 ↔ 中等柔和圆角卡片 + 柔和阴影, 构建可承载内容的「面」.

整体视觉是命名的延伸, 改动配色时应先核对是否仍符合「护眼 / 清新 / 自然 / 专业」四个调性词, 避免引入高饱和色破坏体系.
