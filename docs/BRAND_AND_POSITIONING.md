# 芽绘台 / SproutCanvas — 产品定位与品牌规范

## 1. 产品命名

| 项 | 内容 |
|---|---|
| 中文名 | **芽绘台** |
| 英文名 | **SproutCanvas** |
| 工程代号 | `sprout-canvas` (GitHub 仓库名/包名) |

### 1.1 命名释义
- **芽**: 嫩芽 / 萌发 — 隐喻「一句 prompt 萌发出画面」的创作起点; 同时自带嫩绿色彩, 与界面护眼绿调性同源.
- **绘**: 绘画 / 生图 — 直接点题图像生成, 中和「芽」的轻盈感, 让产品有专业气质.
- **台**: 工作台 / workbench — 强调多 Provider 聚合 + 工作流编排的「平台」属性, 与代号一脉相承.
- **SproutCanvas**: Sprout 对应「芽」, Canvas 是图像创作行业通用术语 (Photoshop / InvokeAI Unified Canvas), 表达「可创作的画面空间」.

### 1.2 命名不适用场景
- 不要简称为「芽」或「Sprout」— 单字/单词会丢失专业感, 且 Sprout 容易与 SproutCore (老牌 JS 框架) 混淆.
- 对外正式文案统一用「芽绘台」, 不用「芽绘工坊 / 芽绘工作台」等变体, 保持唯一识别.

## 2. 产品定位

### 2.1 一句话定位
**芽绘台是一个聚焦图像生成的多 Provider 创作工作台.**

### 2.2 范围 (In Scope)
- 文生图: OpenAI Images API 及兼容网关 (Elysiver / abrdns / AnyRouter 等).
- 图生图: 参考图编辑 / 变体 / 多参考图.
- 提示词优化: 独立文本模型, 风格模板, 反向提示词建议.
- 多服务商管理: 统一参数, 后端代理, API Key 不落前端.
- 作品管理: 输出归档, 参数复用, 下载.

### 2.3 范围外 (Out of Scope)
- **不做视频生成** — 当前阶段视频模型成本和门槛过高, 不纳入产品范围. 上一版 dev 文档 (`ONE_STOP_AI_STUDIO_DEV.md`) 中的视频规划 (V1) 暂时搁置.
- 不做模型训练 / LoRA 训练.
- 不做 Photoshop 级图层编辑.
- 不做团队协作 / 计费 / 多租户 (V2 议题, 暂不启动).

### 2.4 目标用户
- 自己使用 + 小范围分享的图像创作者.
- 需要在多个 API 服务商之间切换比价 / 比效果的进阶用户.
- 看重数据自托管 (API Key 不交给第三方网页) 的隐私敏感用户.

## 3. 视觉品牌规范

### 3.1 调性关键词
**护眼 · 清新 · 自然 · 专业**

低饱和绿调为主, 暖白底打底, 避免高饱和刺眼色; 风格接近「自然光下的纸面 + 嫩叶」, 适合长时间创作.

### 3.2 配色体系 (与 `css/styles.css` 现状对齐)

#### 主色板
| 用途 | 变量名 | 色值 | 说明 |
|---|---|---|---|
| 主强调色 | `--leaf-green` | `#597445` | 叶绿; 按钮 / 主行动 / 焦点环 |
| 强调色 hover | `--leaf-green-hover` | `#4A6338` | 深一档叶绿, 用于 hover/active |
| 次级文字/边框 | `--moss-green` | `#798A6F` | 苔藓灰绿; 次要文字, 边框, 分隔线 |
| 辅助色 | `--sky-blue` | `#8AB4F8` | 天蓝; 信息提示 / 链接 / 标签 |

#### 中性色 (背景与文字)
| 用途 | 变量名 | 色值 | 说明 |
|---|---|---|---|
| 主背景 | `--bg-color` | `#FDFCF8` | 暖纸白; 全局底色, 偏黄白, 不刺眼 |
| 卡片表面 | `--bg-surface` | `#FFFFFF` | 纯白; 内容卡片 |
| 悬浮/次背景 | `--bg-float` | `#F4F5F0` | 微绿白; hover 状态 / 次级容器 |
| 正文文字 | `--earth-brown` | `#333831` | 土褐近黑; 比纯黑柔和, 长阅读护眼 |

#### 状态色 (来自 styles.css 实际使用)
| 用途 | 色值 | 说明 |
|---|---|---|
| 信息 (info) | `#1967D2` (文字) / `rgba(138, 180, 248, 0.1)` (底) | 配 `--sky-blue` 体系 |
| 成功 (done) | `#597445` / `rgba(89, 116, 69, 0.1)` | 复用 leaf-green |
| 错误 (err) | `#C53030` (文字) / `#E2705B` (强调) / `rgba(226, 112, 91, 0.1)` (底) | 砖红, 饱和度受控 |
| 数据标签 | `#F5A623` | 琥珀色, 仅用于数据徽标 |

#### 阴影
- `--shadow-soft`: `0 12px 36px rgba(85, 95, 75, 0.08)` — 卡片默认.
- `--shadow-hover`: `0 16px 48px rgba(85, 95, 75, 0.12)` — hover 抬升.
- 阴影统一带绿灰色调 (而非纯黑), 与整体绿系协调.

### 3.3 圆角与节奏
- `--border-radius-lg: 24px` — 大卡片 / 主面板.
- `--border-radius-md: 16px` — 中等模块 / 按钮.
- `--border-radius-sm: 10px` — 标签 / 输入框.

圆角偏大, 强化柔和清新气质, 避免直角带来的硬朗感.

### 3.4 字体
| 用途 | 字体栈变量 | 字体 |
|---|---|---|
| 界面元素 | `--font-ui` | Outfit, -apple-system, sans-serif |
| 正文 | `--font-body` | Inter, -apple-system, sans-serif |
| 代码/参数 | `--font-mono` | JetBrains Mono, monospace |

### 3.5 动效
- `--transition-fast: 150ms ease-out` — hover / 按下.
- `--transition-normal: 220ms ease-out` — 面板切换 / 内容加载.
- 全部使用 ease-out, 入场快出场慢, 体感轻盈.

## 4. 命名与视觉的协同
- 「芽」的嫩绿语义 ↔ `--leaf-green` (#597445) + `--moss-green` (#798A6F) 的低饱和绿系.
- 「绘」的创作动作 ↔ 暖纸白 (#FDFCF8) 底色, 像在纸上落笔.
- 「台」的工作台属性 ↔ 大圆角卡片 + 柔和阴影, 构建可承载内容的「面」.

整体视觉是命名的延伸, 改动配色时应先核对是否仍符合「护眼 / 清新 / 自然 / 专业」四个调性词, 避免引入高饱和色破坏体系.
