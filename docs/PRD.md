# 芽绘台 / SproutCanvas — 产品需求文档 (PRD)

> 版本: v3.0 (2026-09-05 修订). 本文档是产品功能的**单一事实来源**; 视觉与交互规范见 `docs/DESIGN.md`, 品牌定位见 `docs/BRAND_AND_POSITIONING.md`.
> 三份文档分工: PRD 管「做什么」, DESIGN 管「长什么样、怎么操作」, BRAND 管「是谁、叫什么」.
> v3.0 依据 `stitch_sproutcanvas_studio/` 设计稿 (Botanical Paper Studio 方案) 对 v2.0 信息架构做出修订.

## 1. 概述

### 1.1 一句话定位
自托管的图像生成工作台: 纯 API 驱动 (不跑本地模型), 后端聚合多家服务商, 用户在网页上完成文生图 / 参考图生成 / 局部编辑 / 系列批量生成.

### 1.2 核心价值 (按优先级)
1. **省心**: 提交即走. 排队、调度、服务商选择、失败转移全部由后端自动处理, 用户只面对"排队中 → 生成中 → 完成/失败"三种状态.
2. **易部署**: 单 Node 进程 + 零运行时依赖, Docker/PM2 一条命令起服务.
3. **隐私**: API Key 只存在服务端配置文件, 作品只存浏览器 IndexedDB.

### 1.3 核心设计原则
- **Provider 隐形**: 服务商是后端实现细节, 不是用户概念. UI 中不出现服务商选择器, 不在结果上强调服务商名称. 失败转移全自动 (含熔断), 用户唯一可见的动作是失败后的「重试」. 服务商健康状态、耗时统计属于未来的"设置/诊断"页范畴, 不进入创作流程.
- **文案务实**: 直白短句, 说明"做什么、怎么做"; 禁止修辞、比喻、口号 (见 DESIGN.md §8).

## 2. 目标用户与场景

| 用户 | 场景 | 关键诉求 |
|---|---|---|
| 个人创作者 (主) | 日常出图: 单张精修、参考图改图、局部替换 | 提示词顺手、参数少而够用、结果即时可下载 |
| 系列内容制作者 | 一组同风格图: 表情包、壁纸系列、绘本分镜 | 一个主题拆一批图, 批量提交, 逐张回填 |
| 风格探索者 | 试验不同风格的提示词写法 | 风格库可浏览、可搜索、提示词可复制 |
| 自托管爱好者 | 部署在自己服务器/家庭主机给家人用 | 部署简单、密码即用、数据不出本地 |

非目标用户: 需要团队协作、计费、多租户的团队; 需要本地 GPU 推理、ControlNet、节点编排的重度用户.

## 3. 信息架构 (v3 决策)

**顶部通栏导航 + 四个一级页面** + 全局组件:

```
登录页 (访问密码, 可配置关闭)
└─ 应用框架 (顶部 64px 固定通栏: 品牌 + 导航 + 队列入口 + 主题切换)
   ├─ 单图创作 Studio          [默认页]
   │   ├─ 左侧 440px 参数控制栏 (sticky)
   │   └─ 右侧结果瀑布流 (占位卡 → 回填, 1~2 列大卡)
   ├─ 系列策划 Storyboards      [独立导航项]
   │   ├─ 顶部工作流工具条 (用途类型 + 幕数 stepper + 风格选择)
   │   └─ 分镜卡网格 (4 列, 每卡独立状态)
   ├─ 风格库 Styles             [独立导航项]
   │   └─ 搜索 + 分类 pills + 3 列风格卡网格 + 详情灯箱
   └─ 展馆 Gallery              [本地作品库]
       ├─ 按天分组的作品流 (今日 / 近 7 天 / 更早)
       └─ 大图查看器 (弹层)
全局组件: 队列抽屉 (右侧滑出) / toast (底部胶囊) / 主题切换 (浅/深)
```

**v2 → v3 变更理由** (依据 Stitch 设计稿):
- v2 的左侧 84px 图标栏在四页结构下横向空间利用率低; Stitch 顶栏方案把更多宽度让给创作结果区, 契合"桌面优先、结果区为主角"的定位.
- v2 将单图/系列合并为一页 segmented 切换; Stitch 将系列策划独立成页, 因为系列工作流 (主题 → 拆分 → 逐卡管理) 与单图即时出图的节奏差异大, 混排互相干扰.
- 队列坞 (右下角悬浮) 升级为右侧滑出抽屉: 信息容量更大 (进度、排队位次、取消/置顶), 且不遮挡结果区内容.
- 局部编辑从矩形选区升级为**画笔蒙版涂抹**: 矩形选区对真实"局部改图"需求太粗, 画笔蒙版才能表达"只改这一片". (PRD v2 曾将其列为未来候选, 现提前实装.)

### 3.1 页面职责边界
- **单图创作**: 即时出图. 提示词 + 风格 + 参数 + (可选) 参考图/蒙版 → 单卡循环.
- **系列策划**: 分镜管理. 主题 → 文本模型拆为 N 条子提示词 → 每条一张分镜卡, 独立生成/重绘/微调.
- **风格库**: 资产沉淀. 浏览、搜索、复制提示词、发送到创作台.
- **展馆**: 历史归档. 按天分组浏览、大图查看、下载、删除.

## 4. 功能需求

### 4.1 登录页
- `accessPassword` 非空时启用; 空则直接进入工作台.
- 品牌 logo + 一句话产品说明 + 密码输入 + 登录按钮.
- 登录失败: 内联错误提示, 不跳转.

### 4.2 单图创作页 (默认)

**左侧参数控制栏** (桌面 440px, sticky; 移动端折叠为底部工作表), 自上而下:

1. **灵感提示词**: 大输入区 (auto-grow textarea), 字数统计, 「清空」「润色扩写」(调 `/api/text`) 两个辅助动作.
2. **快捷风格**: 常用风格横滑单选 pills, 选中即附加到提示词; 右上「更多风格」链接跳风格库.
3. **基底垫图与局部重绘**: 参考图上传区 (拖拽/粘贴/从展馆选取), 缩略图管理 (更换/删除); 载入参考图后出现「局部涂抹修改」入口 + 已有蒙版时的状态条.
4. **生成参数** (卡片化, 折叠区): 画面比例 (1:1/16:9/9:16/4:3/3:4/3:2/2:3/21:9/auto, 显示实际像素), 清晰度 (1K; 2K/4K 禁用待解锁), 质量 (auto/快速/标准/精细), 生成数量 (1/2/4), 背景 (自动/不透明/透明 toggle), 输出格式 (auto/PNG/JPEG/WebP), 压缩率 (10-100).
5. **提交按钮**: 「开始绘制」, 全宽主按钮, 显示 ⌘+Enter 快捷键提示.

**右侧结果瀑布流**:
- 头部: 页面标题 + 简短说明 + 过滤 pills (全部/今日/精选标记).
- 大卡 (1 列 ≤1280px, 2 列 ≥1280px), 每卡状态:
  - **生成中**: 呼吸感纸面背景 + 进度环 + 已用时间/排队位次 (诚实进度, 不做假百分比) + 「中断生成」.
  - **完成**: 图 + prompt 摘要 + 元数据胶囊 (尺寸/模式/清晰度) + hover 快速动作 (下载/设为参考图/局部修改/全屏) + 时间戳.
  - **失败**: 错误原因摘要 + 「修改提示词」(聚焦输入区) + 「重试」(后端自动排除已失败服务商).
- **占位关联**: 提交即生成占位卡, 通过 `clientContext.placeholderId` 回填, 见 §5 交互协议.

### 4.3 系列策划页

**顶部工作流工具条**:
- 用途类型 segmented (绘本连环画 / 电商长图 / 视频分镜 / IP图库 — 对应现有 BatchMode 的文案化).
- 幕数 stepper (2-16, 对应系列生成数量).
- 风格选择按钮 (弹风格快选面板, 数据与风格库同源).
- 主题输入行: 故事/主题描述 + 「自动拆解故事」(调 `/api/text` 拆分) + 重置.

**分镜卡网格** (1/2/4 列响应式), 每卡:
- 编号徽标 + 分镜标题 + 状态 (已就绪/渲染中/等待中/失败).
- 预览图区: 完成态带 hover 动作 (查看大图/单镜重绘); 渲染态显示进度; 等待态显示「立即生成」.
- 分镜描述 (可编辑, 2 行截断, 点击展开微调).
- 卡底动作: 微调分镜词 / 局部重绘 / 移除分镜 / 调节参数.
- **分镜插入**: 相邻卡之间有「+ 添加镜头」插入位, 可在任意位置增补分镜.

**批量动作**: 一键渲染全部 / 单镜重绘 / 单镜移除.

### 4.4 风格库页
- 顶部: 页面标题 + 说明文案.
- 搜索栏 (匹配中文名/英文名/描述/标签/分组), ⌘K 快捷聚焦.
- 分组过滤 pills 横滑 (全部/数字与游戏/动漫与插画/传统绘画/版画与印刷/现代视觉/氛围与时代风格...), 显示各组数量.
- 普通风格卡: 中文名 + 英文名 + 描述 + 分组标签.
- 高级风格卡: 上述 + 用法说明 + 示例图 (点击放大查看).
- 每张卡片两个动作: **复制提示词** (本页核心诉求), **发送到创作台** (选中并跳转).
- **详情灯箱**: 点击卡片打开, 展示大图 + 完整提示词模板 (可复制) + 用法说明; 高级风格显示推荐参数.
- 「发送到创作台」后单图创作页参数区可见已选风格 pill (可清除).

### 4.5 展馆页
- 历史作品按日期倒序分组 (今日 / 近 7 天 / 更早), 组头显示当日张数.
- 作品卡: 图片 + prompt 摘要 + 元数据标签 (生成时间/尺寸/模式; **不含服务商**).
- 大图查看器: 左右切换 (按钮 + 键盘), 缩放, prompt 全文, 下载, 删除. 系列作品可展开连贯长图拼版视图.
- 单张删除 + 全部清空 (需确认).
- 数据: 仅浏览器 IndexedDB; 拥浏览浏览器/设备不共享, 明示不做云端同步.

### 4.6 切图工具
- 不占导航位, 从单图创作页参数控制栏的垫图区入口或展馆作品卡动作进入, 以工具抽屉/弹层形式呈现.
- 行 × 列切分原图 (可从展馆/上传取图), 生成切片网格.
- 切片可下载, 可「作为参考图送到创作台」.
- 纯前端操作, 不产生任何任务.

### 4.7 全局组件
- **队列抽屉** (右侧滑出, 352px): 顶栏按钮显示全局进行中/排队数徽标; 抽屉内任务卡列表 (状态/进度/排队位次/prompt 摘要/取消/重试); running 任务不可取消 (单 worker 限制); 底部「清空已完成」. 空闲一段时间自动收起.
- **toast**: 成功/失败/信息三态, 底部胶囊, 自动消失, 不打断操作.
- **主题切换**: 浅色 (默认) / 深色, localStorage 记忆, 首屏内联脚本防闪烁.
- **页脚**: 品牌名 + 版本号; 不放外部链接.

## 5. 交互协议 (技术既定, UI 需适配)

1. 任务提交: `POST /api/jobs/*` → 202 + 任务元数据; 前端 2.2s 轮询 `/api/jobs/me` (有任务 2s / 空闲 5s, 页面隐藏暂停).
2. 结果回填: 占位卡通过 `clientContext.placeholderId` 与任务/结果关联, 完成后拉取 `/api/jobs/:id/result` 填充.
3. 任务元数据仅保留 30 分钟 (进程内存, 重启即失); **作品持久化只在浏览器**.
4. 失败重试语义: 后端自动带上失败链排除; 若无可用服务商则明确报错文案.
5. 严格单 worker 顺序出图; 前端展示诚实排队位次, 不做假进度条百分比 (进度环只表达“生成中”状态, 可显示已等待时长).
6. 文本能力 (润色/拆解) 走 `/api/text`, 按 `textProviders[]` 主备切换; 失败给内联错误, 不阻塞表单.
7. 局部编辑走 `/api/jobs/images/edits` (multipart, `image` + 可选 `mask`); Provider 自动路由只选支持 edits 的服务商.

## 6. 文案规范 (摘要, 详见 DESIGN.md §8)

直白、务实、克制. 说明"做什么、怎么做", 不用修辞、比喻、口号. 例:
- 占位符: "描述主体、风格、构图、光线…" ✓ ; "让灵感在画布上发芽" ✗
- 空态: "提交后会显示当前排队和生成结果." ✓
- 按钮: 「开始绘制」「复制提示词」「发送到创作台」「自动拆解故事」(动词+宾语, 无装饰)
- Stitch 稿中偏文艺的文案 ("自然心流·灵感绘台"、"享受创作心流"、"灵感绘卷与单作珍藏") 一律替换为务实表述.

## 7. 范围外 (明确不做)

- 视频生成、模型/LoRA 训练、Photoshop 级图层、协作/计费/多租户.
- 服务商手动选择 / 服务商管理 UI (设置诊断页为未来议题).
- 展馆云端同步与跨设备.
- 脚本/HUD 类重节点编辑 (Stitch 稿中的 "Node-Flora 节点"、"CFG/步数/种子" 等扩散模型参数仅作视觉占位, 不实现真实功能; 实际参数以 §4.2 为准).

## 7.1 实装取舍 (Stitch 稿 → 实现)

Stitch 稿是视觉与布局蓝图, 以下元素**保留视觉、不实装功能**:
- 结果卡/分镜卡上的百分比进度 (单 worker + 上游不返回进度, 仅显示已等待时长).
- 「置顶」队列操作 (FIFO 公平性优先, 不提供插队).
- 分镜卡「单镜重绘」保留 (等价于对该卡重新提交任务并排除失败链).
- 风格库的「收藏 1,420 次」「典藏推荐」等社交性元数据 (无后端数据源).
- 顶栏「全通道就绪」状态灯 (可等价显示后端 `/ready` 状态, 作为弱化状态点, 不做脉动动画).
- 展馆「云端画纸仓储安全同步中」等云端叙事 (与"数据不出本地"矛盾, 删除).
- 顶栏头像按钮 (无用户体系, 删除; 仅保留主题切换).

## 8. 未来候选 (不承诺)

| 候选 | 价值 | 前置条件 |
|---|---|---|
| 画笔 mask 笔刷升级 (尺寸压感/撤销栈) | 对齐专业编辑体验 | 蒙版画布数据结构 + 上游能力验证 |
| 同 prompt 多服务商对比出图 | 独有卖点, 但与"Provider 隐形"冲突 | 需设计为进阶可选功能, 默认关闭 |
| 任务 SSE 推送替代轮询 | 体验 | 后端改造, 保持零依赖 |
| 展馆筛选/收藏/参数复用 | 资产管理深化 | 展馆数据结构升级 |
| 队列任务置顶 | 批量场景调度 | 破坏用户间 FIFO 公平, 需限次/限场景 |

## 9. 成功标准

- 新用户从部署到第一张图: ≤ 5 分钟 (不含 API Key 申请).
- 常用路径 (写 prompt → 提交 → 下载) 全程无服务商概念暴露.
- 系列模式一次 10 张任务, 用户可中途取消任意未开始任务.
- 双主题下全部界面无对比度不达标文字; 长时间使用 (≥1h) 无刺眼反馈.
