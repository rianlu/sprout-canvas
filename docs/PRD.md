# 芽绘台 / SproutCanvas 产品需求

生效日期: 2026-09-07. 保持 Stitch 五份正式稿的视觉结构, 以本文件和用户最新决策确定功能. 历史 v3 计划不再作为执行清单.

## 1. 定位与范围

- 提供多 Provider 图像创作工作台, 面向个人和可信的小范围使用者.
- 聚焦文生图, 参考图生成, 局部编辑, 系列策划与作品下载.
- 由服务器持有密钥并公平排队, 由浏览器保存作品和创作草稿.
- 不提供作品精选收藏, 回收站, 云端图库, 公开分享链接或账户资料系统.
- 不扩展到视频生成, 模型/LoRA 训练, 团队协作或计费. 保留静态视频分镜模板.

## 2. 信息架构

| 页面 | 主要职责 |
|---|---|
| 单图创作 | 编辑提示词, 应用风格, 参考图/蒙版, 设置参数, 查看本地结果流 |
| 系列策划 | 选择模板, 填写故事梗概或分镜剧本, 拆解 3-8 幕, 检查分镜后确认生成, 重绘和查看版本 |
| 风格库 | 浏览/检索开源预设, 复制中文模板, 向单图载入模板和画风, 向系列应用统一画风 |
| 展馆 | 筛选和检视本地作品, 复用配方, 下载/分享文件, 直接删除 |

- 使用固定顶栏和 URL hash 导航, 支持浏览器前进/后退.
- 在手机上使用第二行导航, 保证队列, 主题与退出按钮位于视口内.
- 提供队列抽屉, 图片查看器, 蒙版编辑器, 单镜参数弹层和帮助弹层.
- 在异步草稿恢复完成后开放编辑, 避免旧草稿覆盖刚修改的参数.

## 3. 单图创作

- 提供提示词编辑, 清空, 文本模型润色和 Cmd/Ctrl + Enter 提交.
- 应用画风和柔和/明艳调性时将实际拼接文本保存到配方. 复用完整配方时不重复追加画风/调性.
- 一次生成 1/2/4 张时分别提交独立任务, 保持服务端单 worker. 逐张显示真实状态和结果.
- 默认使用 `quality=medium`, `outputFormat=png`. 按通道能力提供输出格式.
- 保留正式稿的六种画幅入口, 使用真实请求尺寸. 标准尺寸通道提供 1:1, 3:2, 2:3 和 auto. 恢复配方时显示已保存的比例.
- 将请求尺寸定义为目标规格; 在结果卡和查看器中展示文件的实际尺寸. 不把 2K/4K 映射或模板中的 8K 文案作为通道效果承诺.
- 提供自动/不透明/透明背景, 禁止 JPEG 与透明背景组合. 保留 PNG/WebP 输入的透明信息.
- 保存参数, 参考图, 矢量笔画或已恢复的栅格蒙版, 支持刷新继续编辑.

### 3.1 参考图与局部编辑

- 在同一图片入口中明确区分参考图生成与局部重绘. 参考图生成允许重新设计构图, 画幅和风格; 局部重绘只编辑指定区域.
- 从作品进入局部重绘时读取该作品配方, 继承目标尺寸, 质量, 背景, 文件格式, 压缩率和原通道. 以只读摘要显示参数, 不使用创作页当前值或默认 1:1 覆盖.
- 对未记录生成配方的上传图片或旧作品使用自动尺寸, 按原图比例编辑, 明确显示本次使用的默认质量/格式. 不编造历史参数.
- 将当前选中作品的原图作为新编辑基底, 不恢复生成该作品时使用的旧参考图或旧蒙版.
- 使用独立的局部修改要求, 保持原图画风, 不追加创作页的其他风格模板和渲染调性. 每次局部编辑生成 1 张新作品, 保留 parentId 和版本; 系列作品同时保留原 seriesId/sceneId.
- 清空蒙版后保持局部编辑模式并阻止提交, 禁止静默切成整图生成. 只有显式切换参考图生成时清除蒙版并开放参数调整.
- 允许上传/更换/移除参考图. 完整配方可恢复多参考图, 契约最多接受 4 张, 每张最多 12 MiB.
- 在单图图片入口保留原文件. 局部编辑提交原图和等尺寸蒙版, 不隐式缩小或重新压缩原图; 超出 12 MiB 时明确提示处理后再上传.
- 以第一张参考图的实际尺寸建立蒙版. 涂抹区使用透明像素表示允许修改, 橡皮擦恢复不透明保留区.
- 校验图片真实 MIME, 蒙版透明通道和尺寸, 在请求进入上游前拒绝不一致输入.
- 保存蒙版成功后才关闭编辑器或提示成功. 本地保存失败时保留错误与重试机会.
- 将保存蒙版与执行生成分开. 保存后使用开始局部重绘按钮或 Cmd/Ctrl + Enter 提交.
- 将参考图和蒙版交给服务端适配层转换为上游协议, 不让浏览器自行构造不同 Provider 的请求.
- 对完成作品提供原图下载, 设为参考, 局部修改和查看器. 将切图拆分放入卡片的二级工具入口.

## 4. 系列策划

| 模板 | 拆解要求 |
|---|---|
| 绘本连环画 | 按开端, 发展, 转折和结尾分镜, 每幕一个明确动作 |
| 电商长图 | 按首屏, 卖点, 材质细节, 使用场景和陈列分图, 不编造价格/销量/功效 |
| 视频分镜 | 明确景别, 机位, 运动意图与动作, 只生成静态镜头 |
| 品牌 IP 延展 | 按基础形象, 表情, 动作和场景应用生成独立图片, 不合并成九宫格 |

- 使用严格 JSON 分镜计划, 校验模板, 幕数, 标题和提示词. 每个生成请求只生成当前一幕.
- 将流程分为智能拆解分镜, 逐镜检查修改, 确认并生成图片. 拆解只调用文本服务并保存可编辑草稿, 不创建图片任务或写入生图 outbox.
- 将确认生成入口放在分镜下方, 显示本次图片数量. 所有分镜提示词完整后才允许提交, 使用用户修改后的提示词和本镜参数; 禁止提交时自动补拆解并直接生图.
- 恢复待确认草稿时保持待确认状态, 不自动入队. 将梗概输入框中的 ⌘/Ctrl + Enter 仅绑定为拆解, 不给分镜编辑或确认生成绑定全局快捷键.
- 重新拆解前确认覆盖已有提示词, 取消或拆解失败时保留原稿. 拆解期间阻止重复调用和改写正在使用的输入.
- 仅提供系列故事梗概 / 分段分镜剧本这一主文本入口, 将角色或商品特征写入其中, 由拆解规则提取. 不增加独立主体设定字段, 不读取或保存旧草稿中的该字段.
- 将可选参考图入口收在统一画风 / 基底区. 后续分镜使用首镜参考, 结合梗概, 当前分镜和风格维持视觉连贯.
- 不使用锁脸, 绝对一致或逐像素复现承诺. 参考链能传递上下文, 输出一致性仍依赖上游.
- 使用稳定的 `seriesId` 与 `sceneId`, 为每次重绘建立新作品 ID, version 和 parentId.
- 允许调整本镜提示词, 画幅, 质量和格式. 待执行任务通过 PATCH 原地更新; 已完成任务创建新版本.
- 只允许在当前用户自己的队列中置顶, 保持用户间公平轮询.
- 在提交前保存完整批次及请求编号. 部分受理失败后只续交未受理分镜, 刷新后保留续交入口.
- 在首镜内存已释放时从浏览器提供原始首镜图片, 由服务端校验哈希, 不重复生成首镜.
- 提供网格/时间轴, 单镜查看, 版本切换和整套 ZIP.
- 从展馆衍生系列时带入原模板, 风格, 画幅, 质量, 格式, 本镜参数与主体参考; 创建独立的系列/分镜身份.
- 新建系列时清空故事, 分镜, 主体参考和版本身份.

## 5. 风格库

- 使用指定开源项目 `gpt-image2/awesome-gptimage2-prompts` 的资料重建预设, 删除旧 80 款数据与无引用旧配图.
- 维护 36 个独立预设, 分为插画与纸本, 摄影与光影, 三维与微缩, 海报与排版, 角色与分镜, 信息与品牌 6 类, 每类 6 款.
- 从实际条目计算总数/分类数, 不复刻设计稿的 48 或上游 README 的过期统计.
- 提供搜索, 分类, 展示密度, 详情, 模板复制和发送到当前创作页.
- 将卡片预览, 详情, 复制和发送到单图统一到同一份完整中文模板. 保留画面明确要求的英文文字与品牌名, 不用画风简介替代完整模板.
- 发送到单图时先保存传入草稿, 再载入模板和画风并提示成功. 切换到文生图, 清除旧参考图, 蒙版和作品来源身份, 关闭额外渲染调性, 将数量设为 1; 保留画幅, 质量和格式设置. 允许继续编辑, 刷新后保持内容, 由用户点击开始绘制后再提交.
- 将画风与提示词一起持久化, 保证新模板优先于旧草稿. 使用共享提示词长度上限, 避免长模板粘贴时截断.
- 发送到系列时仅更新统一画风, 保留故事梗概, 分镜提示词与参数, 不自动拆解或生图.
- 在详情保留原作者, 原始作品链接, CC BY 4.0 许可和改编说明. 示例图只用于展示来源风格.
- 移除其他工具专用参数和未经验证的分辨率标注. 不展示 CFG/步数等参考数值.

## 6. 展馆与本地数据

- 在当前浏览器 IndexedDB 保存作品元信息, 原图 Blob, 缩略图, 参考素材和消费记录.
- 按单图/系列, 四类模板来源, 比例, 生成时间和提示词筛选. 以本地数据生成真实数量.
- 对系列显示最新分镜版本, 在查看器中切换旧版本, 保留主提示词和本镜提示词层次.
- 在详情中优先展示大图, 默认按可用区域等比适应, 提供原始大小, 按钮/滚轮/双指缩放和拖动查看. 仅缩放图片, 保持下载, 全屏和关闭等操作尺寸固定.
- 允许收起配方信息扩大查看区. 手机默认展示图片, 通过详情按钮查看参数和再创作操作. 全屏保留完整工具栏, 切换作品, 分镜或版本后重新适应窗口.
- 在完整配方中保存实际提交文本, 模型, Provider, 风格, 调性, 目标尺寸, 质量, 背景, 格式, 压缩率与参考素材身份.
- 提供完整配方复用. 对缺少配方的旧作品只展示已知信息, 不补造历史参数.
- 按需读取缩略图/原图, 按实际文件类型命名下载. ZIP 包含选中的原始文件.
- 在支持 Web Share 文件分享的浏览器中提供分享按钮, 只交给系统选定文件, 不创建服务器公开链接.
- 删除前明确提示永久删除. 删除成功后更新 UI, 清除相关缩略图和不再引用的素材; 删除系列包含旧版本.
- 将保存作品与消费任务 ID 放在同一事务中. 删除后刷新不得重新导入已消费结果.
- 区分空库, 读取失败和写入失败. 多图写入失败时整批回滚, 不显示保存成功.

## 7. 队列, 会话与恢复

1. 由浏览器先保存 outbox, 使用 `POST /api/jobs` 提交领域请求并获得 202.
2. 以 `requestId` 保证提交幂等, 拒绝同 ID 的不同生成意图.
3. 有活动任务时每 2 秒轮询, 空闲时每 5 秒轮询; 隐藏页面暂停, 返回页面后恢复.
4. 完整同步活动任务与未领取结果. 历史使用游标分页, 支持加载更早任务.
5. 本地事务完成后才 ack; 遇到配额或网络错误保留恢复机会, 不提前丢弃临时结果.
6. 将队列归档与作品删除分开, 持久化收起已保存/已取消任务的状态.
7. pending 可取消或编辑; 已发送到上游的任务不承诺可撤回.
8. SQLite 保存任务元信息/幂等键 7 天, 保存会话 token 的 SHA256. 禁止保存图片, 蒙版或带图请求正文.
9. 图片仅在内存临时中转, 通常保留 30 分钟; ack 且无活动依赖后释放. 重启后未领取图片无法从服务器恢复.
10. 重启后的 pending 使用本地原始配方恢复. running 标记为结果未知, 不自动再次发起可能已计费的生成.
11. 接入退出和会话过期重新登录. 不将浏览器会话隔离描述为独立账户或跨设备作品同步.
12. 提供使用帮助与通道状态, 区分未验证, 可用, 最近失败和熔断冷却. 服务连通不代表上游已验证.

### 7.1 参数与进度规则

- 不提供 Seed, CFG, 步数, 参考图数值权重. 官方图像接口未提供这些字段, 当前通道接受非法值也不能证明参数有效.
- 不提供随机百分比或准确剩余时间. 只展示真实状态, 已用时长和队列位次.
- 根据 [真实通道验证](REAL_API_VALIDATION.md) 限制当前通道为 PNG, 在界面说明目标尺寸与实际输出的区别.
- 将 Responses 的模拟协议验证与真实通道验证分开记录, 不把前者描述为后者.

## 8. 验收要求

- 验证四页在桌面/平板/手机和深浅主题下的布局, 同时检查文档溢出和关键按钮边界.
- 验证多任务, 蒙版透明语义, 真实文件格式, 原子领取, 删除后刷新, 配方恢复, 旧数据迁移和存储失败恢复.
- 验证分镜独立身份, 待执行编辑, 置顶, 版本, 部分失败续交, 模板分类和 ZIP 文件完整性.
- 验证异常请求不会终止服务, 用户看不到其他用户任务, 超过 50 个未领取结果不丢失, 重启状态不触发自动重发.
- 验证本地/容器构建产物一致, Node 22 启动, SQLite 会话恢复和健康检查.
- 在 [功能清单与架构评估](FEATURE_ARCHITECTURE_REVIEW.md) 记录结果与限制, 不以 UI 截图代替真实模型效果验收.
