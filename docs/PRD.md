# 芽绘台 / SproutCanvas 产品需求

生效日期: 2026-09-13. 保持 Stitch 五份正式稿的视觉结构, 以本文件和用户最新决策确定功能. 历史 v3 计划不再作为执行清单.

## 1. 定位与范围

- 提供多 Provider 图像创作工作台, 面向个人和可信的小范围使用者.
- 聚焦文生图, 参考图生成, 局部编辑, 系列策划与作品下载.
- 由服务器持有密钥并公平排队, 由浏览器保存作品和创作草稿.
- 不提供作品精选收藏, 回收站, 云端图库, 公开分享链接或账户资料系统.
- 不扩展到视频生成, 模型/LoRA 训练, 团队协作或充值支付. 使用访问码与灵感点控制小范围测试额度, 保留静态视频分镜模板.

## 2. 信息架构

| 页面 | 主要职责 |
|---|---|
| 单图创作 | 编辑提示词, 应用风格, 参考图/蒙版, 设置参数, 查看最近 4 个创作记录 |
| 系列策划 | 选择模板, 填写故事梗概或分镜剧本, 拆解 3-8 幕, 检查分镜后确认生成, 重绘和查看版本 |
| 风格库 | 浏览/检索已上架素材, 按原文复制完整模板并发送到单图创作 |
| 管理后台 | 独立管理员登录, 仪表盘汇总风格/访问码/结算用量与待核实事项, 分别维护风格素材与访问码/灵感点 |
| 展馆 | 筛选和检视本地作品, 复用配方, 下载/分享文件, 直接删除 |

- 使用固定顶栏和 URL hash 导航, 支持浏览器前进/后退.
- 为四个前台页面使用相同的 80% 纸面底色与 24px 背景模糊, 保持滚动时的毛玻璃效果和深浅主题可读性.
- 在手机上使用第二行导航, 保证灵感点, 队列和用户入口位于视口内.
- 在顶栏加粗灵感点文字和余额, 将访问名称, 深浅色切换, 使用帮助和退出放入用户浮窗. 让浮窗支持点击外部, Esc 和键盘移出关闭; 保留主题本地记忆, 不展示通道健康状态.
- 从普通会话返回当前访问码的只读访问名称, 复用原备注字段, 不增加账号或资料编辑. 后台标明用户可见, 空名称显示创作者; 同码共享名称和余额, 退出只结束当前浏览器会话.
- 提供队列抽屉, 图片查看器, 蒙版编辑器, 单镜参数弹层和帮助弹层.
- 在异步草稿恢复完成后开放编辑, 避免旧草稿覆盖刚修改的参数.
- 仅将未提交, 生成中, 失败或部分完成的内容作为可恢复草稿. 在关联的全部图片任务成功保存到本地后结束草稿, 下次刷新或重新进入时清空文案与参考素材; 保留画幅, 质量, 格式和调性等常用设置, 清理已完成模板的身份, 不删除作品.
- 按提交时的草稿版本关联完整请求集合, 不用返回图片数量判断是否全部完成. 重试沿用同一草稿关联, 本地保存失败时继续保留草稿. 生成期间修改的新输入或新建的策划不得被旧任务完成通知清除.
- 完成后保留当前页面的输入和结果供查看或再次调整, 不突然清空正在查看的工作区. 再次提交时建立本次任务关联, 刷新不自动生成图片.
- 对缺少提交关联的既有草稿保留内容, 使用新建创作或新建系列清空; 不仅凭提示词相同推断它已经完成.

## 3. 单图创作

- 将创作画卷限制为最多 4 张卡片, 优先最近提交的批次, 不足时补充最近已保存作品. 同一任务从排队/生成/保存到成功或失败保持卡片位置, 更多任务从全局队列查看, 全部作品从展馆查看.
- 保存批次编号和提交时间作为本地作品元信息, 保持刷新, 任务历史清理和迟到结果后的排序稳定; 不按展示数量删除作品, 丢弃结果或改变任务与扣点规则.
- 在单任务意外返回多张图片时, 优先保留本批每个请求的主卡, 空位再显示额外输出; 全部图片继续保存到展馆.
- 移除全部画稿/今日作品筛选, 提供前往展馆入口. 桌面保留左右两栏并使用整页滚动, 取消配置栏吸顶; 手机使用单列整页滚动.
- 提供提示词编辑, 清空, 文本模型润色和 Cmd/Ctrl + Enter 提交.
- 在润色指令中按原文完整程度调整表达, 保留语言, 主体与数量, 画面文字, 品牌, 数字单位, 占位符, 排版与限制条件. 不强行缩为一句话或 60 字, 不改变指定画风或添加无效模型参数. 服务端先校验非空与 24000 字符上限, 超长结果按失败返还, 不截断后收费.
- 将最近一次润色前后版本与当前草稿一起保存, 提供撤销润色/恢复润色, 切换时保留两侧手工修改, 刷新后继续可用. 连续润色更新最近一次的版本对, 新建创作, 载入模板/作品配方或完成草稿时清理旧历史. 切换版本不调用模型也不扣点, 已成功调用不因撤销返还.
- 在润色期间只读提示词, 禁用清空, 重复润色与生成, 以植物绿边框流光提示处理中; 结束或失败后恢复编辑. 仅使用外层焦点轮廓, 不显示输入框双边框, 减少动态效果时使用静态描边.
- 在润色结果与历史成功保存后才结束领取. 保存失败保留原请求, 刷新和润色指令更新后优先按原编号领取, 不重复调用或计费; 检查草稿是否已切换或被其他标签页修改, 不以迟到结果覆盖新内容.
- 从风格库载入完整提示词原文, 保留模板编号, 名称, 示例图地址, 作者与分类快照. 在提示词下方用紧凑卡片仅展示示例图和名称, 提供更换与移除; 不在创作卡片展示作者, 分类或常驻说明, 在风格库保留作者署名. 移除关联保留当前文案, 刷新保留所选模板. 不追加独立画风描述, 不将示例图自动作为参考图. 仅在用户明确选择柔和/明艳调性时追加对应文本并保存实际请求到配方. 复用完整配方时不重复追加调性.
- 保留风格库作为模板入口, 不恢复基础画风快捷项; 允许用户直接在提示词中描述画风.
- 始终提供不额外调整, 柔和自然, 生动鲜明三种调性. 将不追加调性描述标为不额外调整, 不称为原始配方或暗示从上传图片读取了配方. 上传参考图时保留当前选择, 从已有作品设为参考或复用完整配方时关闭额外调性.
- 一次生成 1/2/4 张时以一个批次原子受理全部任务并预占点数, 保持服务端单 worker. 逐张显示真实状态和结果, 逐项结算.
- 重试失败画稿时, 让确认入队的新任务接替原占位, 仅显示最新尝试. 在任务历史中保留原失败状态和重试关系, 刷新, 归档完成任务或删除生成作品后不得恢复旧失败卡.
- 在重试提交期间禁用重复操作. 提交未确认或被拒绝时保留原失败卡和可继续提交的请求编号, 不额外显示本地重试占位; 拒绝从已有后续任务的历史失败再次发起重试.
- 默认使用 `quality=medium`, `outputFormat=png`. 按通道能力提供输出格式.
- 将格式控件标为生成格式. 仅支持一种格式时展示固定值和通道限制说明, 多格式时提供可切换的选中状态. 能力未读取完成前显示加载状态并禁止提交, 不提前展示未经确认的格式. 下载继续使用原图的实际格式, 不将生成格式误称为下载转换选项.
- 保留正式稿的六种画幅入口, 使用真实请求尺寸. 标准尺寸通道提供 1:1, 3:2, 2:3 和 auto. 恢复配方时显示已保存的比例.
- 将请求尺寸定义为目标规格; 在结果卡和查看器中展示文件的实际尺寸. 不把 2K/4K 映射或模板中的 8K 文案作为通道效果承诺.
- 提供自动/不透明/透明背景, 禁止 JPEG 与透明背景组合. 保留 PNG/WebP 输入的透明信息.
- 保存参数, 参考图, 矢量笔画或已恢复的栅格蒙版, 支持刷新继续编辑.
- 提供新建创作, 一次清空文案, 参考图, 蒙版和作品编辑来源, 返回文生图并保留常用参数. 在提交或润色期间禁用该按钮.

### 3.1 参考图与局部编辑

- 在同一图片入口中明确区分参考图生成与局部重绘. 参考图生成允许重新设计构图, 画幅和风格; 局部重绘只编辑指定区域.
- 从作品进入局部重绘时读取该作品配方, 继承目标尺寸, 质量, 背景, 文件格式, 压缩率和原通道. 以只读摘要显示参数, 不使用创作页当前值或默认 1:1 覆盖.
- 对未记录生成配方的上传图片或旧作品使用自动尺寸, 按原图比例编辑, 明确显示本次使用的默认质量/格式. 不编造历史参数.
- 将当前选中作品的原图作为新编辑基底, 不恢复生成该作品时使用的旧参考图或旧蒙版.
- 使用独立的局部修改要求, 保持原图画风, 不追加创作页的其他风格模板和渲染调性. 每次局部编辑生成 1 张新作品, 保留 parentId 和版本; 系列作品同时保留原 seriesId/sceneId.
- 清空蒙版后保持局部编辑模式并阻止提交, 禁止静默切成整图生成. 只有显式切换参考图生成时清除蒙版并开放参数调整.
- 允许一次多选或追加参考图, 最多 4 张, 每张最多 12 MiB. 按上传顺序编号并逐张展示缩略图, 文件名, 更换与移除入口; 单张操作不得改变其他图片, 超量或有文件读取失败时保留原有列表. 将全部参考图及顺序保存到草稿, outbox 与完整配方, 刷新与复用不得丢失. 按输出张数计费, 不按参考图数量增加灵感点.
- 从多图参考进入局部重绘时先选择一张原图, 选择期间阻止按钮和快捷键生图. 仅将选中原图与蒙版提交, 其余参考图留在草稿中, 切回参考图生成时恢复原顺序. 沿用现有单份创作草稿, 不引入双模式独立草稿. 参考模式通过顶部局部重绘切换, 隐藏重复的涂抹按钮; 编辑模式按蒙版状态显示绘制蒙版或编辑蒙版. 在前后端拒绝蒙版搭配多张原图的请求.
- 在参考区完全为空且不是蒙版编辑时, 支持拖入图片或在左侧配置区按 Cmd/Ctrl + V 粘贴图片. 已有参考图, 原作品或蒙版时忽略粘贴和拖拽, 不覆盖也不弹窗; 保留普通文字粘贴与显式更换图片. 对连续图片输入加锁, 只载入首张, 读取期间切换素材不得覆盖后选择的内容.
- 在单图图片入口保留原文件. 局部编辑提交原图和等尺寸蒙版, 不隐式缩小或重新压缩原图; 超出 12 MiB 时明确提示处理后再上传.
- 以第一张参考图的实际尺寸建立蒙版. 涂抹区使用透明像素表示允许修改, 橡皮擦恢复不透明保留区.
- 校验图片真实 MIME, 蒙版透明通道和尺寸, 在请求进入上游前拒绝不一致输入.
- 保存蒙版成功后才关闭编辑器或提示成功. 本地保存失败时保留错误与重试机会.
- 将保存蒙版与执行生成分开. 保存后使用开始局部重绘按钮或 Cmd/Ctrl + Enter 提交.
- 将参考图和蒙版交给服务端适配层转换为上游协议, 不让浏览器自行构造不同 Provider 的请求.
- 对完成作品提供原图下载, 设为参考, 局部修改和查看器. 将切图拆分放入卡片的二级工具入口.
- 在切图完成后提供全部切片的 ZIP 打包下载, 同时保留单张下载和送创作. 按原图名称与行列位置命名, 使用切片实际格式; 下载当前完成批次, 不将后来调整的行列/格式套用到旧结果. 更换原图后清除旧切片并取消旧切分结果写入. 在浏览器完成切图与打包, 不调用模型或扣点.

## 4. 系列策划

| 模板 | 拆解要求 |
|---|---|
| 绘本连环画 | 按开端, 发展, 转折和结尾分镜, 每幕一个明确动作 |
| 电商长图 | 按首屏, 卖点, 材质细节, 使用场景和陈列分图, 不编造价格/销量/功效 |
| 视频分镜 | 明确景别, 机位, 运动意图与动作, 只生成静态镜头 |
| 品牌 IP 延展 | 按基础形象, 表情, 动作和场景应用生成独立图片, 不合并成九宫格 |

- 使用严格 JSON 分镜计划, 校验模板, 幕数, 标题和提示词. 每个生成请求只生成当前一幕.
- 将流程分为智能拆解分镜, 逐镜检查修改, 确认并生成图片. 拆解只调用文本服务并保存可编辑草稿, 不创建图片任务或写入生图 outbox.
- 将确认生成入口放在分镜下方, 显示本次图片数量. 所有分镜提示词完整后才允许提交, 使用用户修改后的提示词和本镜参数; 禁止提交时自动补拆解并直接生图.
- 恢复待确认草稿时保持待确认状态, 不自动入队. 将梗概输入框中的 ⌘/Ctrl + Enter 仅绑定为拆解, 不给分镜编辑或确认生成绑定全局快捷键.
- 重新拆解前确认覆盖已有提示词, 取消或拆解失败时保留原稿. 拆解期间阻止重复调用和改写正在使用的输入.
- 仅提供系列故事梗概 / 分段分镜剧本这一主文本入口, 将角色或商品特征写入其中, 由拆解规则提取. 不增加独立主体设定字段, 不读取或保存旧草稿中的该字段.
- 在系列主体参考区提供可选参考图. 从梗概和分镜提取画面风格要求, 结合首镜参考保持连贯. 移除系列中的风格库选择入口, 不把用于单图的完整案例模板追加到每个分镜.
- 不使用锁脸, 绝对一致或逐像素复现承诺. 参考链能传递上下文, 输出一致性仍依赖上游.
- 使用稳定的 `seriesId` 与 `sceneId`, 为每次重绘建立新作品 ID, version 和 parentId.
- 允许调整本镜提示词, 画幅, 质量和格式. 待执行任务通过 PATCH 原地更新; 已完成任务创建新版本.
- 只允许在当前用户自己的队列中置顶, 保持用户间公平轮询.
- 在提交前原子保存完整批次及请求编号. 服务端全批受理或拒绝, 断网后查回原任务并仅续交未受理分镜, 刷新后保留续交入口.
- 在续交恢复时保留完整批次身份; 待执行分镜确认修改后同步草稿关联. 全部关联任务成功保存后清理梗概, 分镜提示词, 参考图和版本身份, 下次进入开启新策划; 保留已生成的全部作品版本.
- 在首镜内存已释放时从浏览器提供原始首镜图片, 由服务端校验哈希, 不重复生成首镜.
- 提供网格/时间轴, 单镜查看, 版本切换和整套 ZIP.
- 从展馆衍生系列时带入原系列模板, 梗概/分镜画面要求, 画幅, 质量, 格式, 本镜参数与主体参考; 创建独立的系列/分镜身份.
- 新建系列时清空故事, 分镜, 主体参考和版本身份.

## 5. 风格库与管理

- 首次从指定开源项目整理的 36 款素材初始化服务端目录, 保留 6 类初始分类及作者/来源/许可. 后续以管理员维护的内容为准, 不在更新或重启时恢复已删除条目或覆盖修改.
- 从已上架条目动态计算总数与分类数, 提供搜索, 分类, 展示密度, 详情, 复制和发送单图. 删除前端静态风格清单及画风描述拼接体系.
- 在独立管理入口中维护图片与完整提示词, 作者可留空; 名称, 分类, 来源链接和排序为可选项. 不要求标签, 英文名或独立画风描述, 不自动翻译或改写用户录入的原文.
- 同时支持选择图片上传, 拖拽和剪贴板粘贴. 对示例图做适合浏览的尺寸规范化, 不影响生成原图/参考图的保真规则.
- 支持新增, 编辑, 上下架与永久删除, 删除后清理无引用图片. 使用版本校验避免多页面编辑互相覆盖; 保存失败或管理会话过期时保留当前表单, 重新登录后继续.
- 将管理权限与普通生成权限隔离, 管理员登录不获得生图权限, 普通登录不获得管理权限.
- 将用户端与管理端入口分开, 不在用户端风格库或公共导航显示管理按钮; 通过独立管理地址进入后台并单独登录.
- 将卡片预览, 详情, 复制和发送单图统一到同一份完整原文, 保留段落换行和作者指定文字.
- 发送单图时先保存传入草稿再导航, 保存模板预览信息与提示词快照. 切换到文生图, 清除旧参考图, 蒙版和作品来源, 关闭额外调性, 数量设为 1; 保留画幅, 质量和格式. 用户修改并点击开始绘制后才提交.
- 不把示例图自动作为生成参考图. 不将模板用于系列统一画风选择; 系列按梗概/分镜/参考链维持画面要求.
- 支持导出包含文本和图片的完整备份. 导入先验证全部内容并展示新增/更新/相同数量, 确认后按编号事务合并, 不删除备份外已有条目; 重复导入相同备份不得重复添加或增加版本.
- 校验录入和合并后整个目录仍能被完整备份并恢复. 保持本机手动测试与 Docker 的数据目录及网页地址隔离, 通过备份迁移需要保留的风格.
- 在详情按实际条目展示许可. 更换作者, 来源或图片后移除不再适用的初始素材许可, 不将新素材自动标成 CC BY 4.0.
- 在同一独立后台提供仪表盘, 风格管理与访问码管理, 默认进入仪表盘. 用子页地址保留刷新位置与浏览器前进/后退, 不增加模型通道配置, 充值支付, 账户资料或云端作品库.
- 从服务端真实记录汇总风格总数/上架状态, 未删除访问码的启停数量, 已结算图片/文字用量与待核实事项. 按任务原点值和额度模式统计, 区分实际扣减与无限额度等值用量, 保留已删除访问码的历史用量; 排除预占, 返还和待核实操作.
- 为灵感点用量和创作使用卡片分别提供今日/本月/累计切换, 默认本月. 固定按北京时间统计成功结算日期, 不受浏览器或 Docker 时区影响; 生图和文字均按已结算任务计次. 为风格数, 访问码状态和待核实数量保留当前快照, 不应用时间筛选.
- 用最近 365 天含当天的真实结算记录绘制每日活跃度热力图. 空白日期记为零, 允许点击或键盘选择日期查看生图次数, 文字次数和等值点数; 手机横向滚动查看历史, 默认定位最近日期. 重复结算与结果清理不改变统计日期, 手动核实成功计入核实结算当天.
- 在桌面用四列紧凑卡片展示管理风格, 中等屏幕三列, 平板两列, 手机单列. 点击整卡打开编辑弹窗, 将上下架和删除保留为独立动作. 直接展示名称, 分类, 提示词, 作者, 排序和来源字段, 保留图片与提示词必填规则.
- 从仪表盘最近风格打开对应编辑表单, 从待核实事项打开对应访问码的用量明细. 每次进入和可见时定期更新统计, 读取失败提供重试并明确标注上次数据. 不读取用户生成图片或调用模型来生成仪表盘内容.

## 6. 展馆与本地数据

- 在当前浏览器 IndexedDB 保存作品元信息, 原图 Blob, 缩略图, 参考素材和消费记录.
- 按单图/系列, 四类模板来源, 比例, 生成时间和提示词筛选. 以本地数据生成真实数量.
- 对系列显示最新分镜版本, 在查看器中切换旧版本, 保留主提示词和本镜提示词层次.
- 在详情中优先展示大图, 默认按可用区域等比适应, 提供原始大小, 按钮/滚轮/双指缩放和拖动查看. 仅缩放图片, 保持下载, 全屏和关闭等操作尺寸固定.
- 允许收起配方信息扩大查看区. 手机默认展示图片, 通过详情按钮查看参数和再创作操作. 全屏保留完整工具栏, 切换作品, 分镜或版本后重新适应窗口.
- 在完整配方中保存实际提交文本, 模型, Provider, 风格, 调性, 目标尺寸, 质量, 背景, 格式, 压缩率与参考素材身份.
- 提供完整配方复用. 对缺少配方的旧作品只展示已知信息, 不补造历史参数.
- 按需读取缩略图/原图, 按实际文件类型命名下载. ZIP 包含选中的原始文件.
- 在支持 Web Share 文件分享的浏览器中提供分享按钮, 只交给系统选定文件, 不创建服务器公开链接.
- 删除前明确提示永久删除. 删除成功后更新 UI, 清除相关缩略图和不再引用的素材; 删除系列包含旧版本.
- 将保存作品与消费任务 ID 放在同一事务中. 删除后刷新不得重新导入已消费结果.
- 区分空库, 读取失败和写入失败. 多图写入失败时整批回滚, 不显示保存成功.

## 7. 队列, 会话与恢复

1. 由浏览器先保存 outbox, 使用 `POST /api/jobs` 或 `/api/jobs/batch` 提交领域请求, 经授权和预占后获得 202.
2. 以 `requestId` 保证提交幂等, 拒绝同 ID 的不同生成意图.
3. 有活动任务时每 2 秒轮询, 空闲时每 5 秒轮询; 隐藏页面暂停, 返回页面后恢复.
4. 完整同步活动任务与未领取结果. 历史使用游标分页, 支持加载更早任务.
5. 本地事务完成后才 ack; 遇到配额或网络错误保留恢复机会, 不提前丢弃临时结果.
6. 将队列归档与作品删除分开, 持久化收起已保存/已取消任务的状态.
7. pending 可取消或编辑; 已发送到上游的任务不承诺可撤回.
8. 任务 SQLite 保存元信息/幂等键 7 天和会话 token 的 SHA256, 不保存生成图片, 蒙版或带图请求正文. 在独立风格 SQLite 保存管理员录入内容, 示例图作为独立文件持久化.
9. 生成图片仅在内存临时中转, 通常保留 30 分钟; ack 且无活动依赖后释放. 重启后未领取图片无法从服务器恢复.
10. 重启后的 pending 使用本地原始配方恢复. running 标记为结果未知, 不自动再次发起可能已计费的生成.
11. 使用访问码登录, 为浏览器分配服务端身份, 支持退出和会话过期重新登录. 停用或重置码后限制旧会话新建任务, 保留在途结果领取. 不将浏览器会话隔离描述为独立账户或跨设备作品同步.
12. 在用户浮窗提供使用帮助, 说明创作, 点数结算与本地保存, 不向普通用户展示通道运行状态. 保留实际操作失败的原因与重试入口.

### 7.1 参数与进度规则

- 不提供 Seed, CFG, 步数, 参考图数值权重. 官方图像接口未提供这些字段, 当前通道接受非法值也不能证明参数有效.
- 不提供随机百分比或准确剩余时间. 只展示真实状态, 已用时长和队列位次.
- 根据 [真实通道验证](REAL_API_VALIDATION.md) 限制当前通道为 PNG, 在界面说明目标尺寸与实际输出的区别.
- 将 Responses 的模拟协议验证与真实通道验证分开记录, 不把前者描述为后者.

### 7.2 小范围使用的基础保护

- 限制普通登录的错误尝试, 对普通与管理写接口统一校验浏览器来源, 严格检查 JSON 请求类型.
- 限制文本调用的并发和频率, 超限时显示可读提示, 不自动重新发起付费调用.
- 下载上游图片链接前检查公开地址与 DNS, 固定已验证的连接地址, 对重定向重新检查, 限制下载时长和大小.
- 对应用文件日志限制单份大小和保留份数, 使写入失败可见; 按 [部署指南](DEPLOY.md) 维护阈值与升级操作.

### 7.3 访问码与灵感点

- 由管理员创建安全随机访问码, 填写用户可见的访问名称和初始额度, 支持批量创建. 完整码仅在创建或重置时显示, 服务端仅保存哈希与尾号.
- 允许多人共用同一码并共享余额, 不设置码有效期. 将点数归属与任务归属分开, 同码使用者不能互相查看, 编辑, 取消或领取任务. 不将前端传入的用户编号视为授权.
- 默认每个图片任务 10 灵感点, 每次文字处理 1 灵感点. 在后台提供两项正整数点值设置, 对图片的文生图/参考图/蒙版及文字的润色/分镜拆解统一计次.
- 默认使用有限额度, 允许管理员在创建或编辑时选择无限额度. 保留切换前的余额, 无限任务不预占或扣减有限余额, 仍记录等值用量. 切回有限额度后使用保留的余额; 已受理及恢复任务继续使用原额度模式, 旧页面提交新任务需确认最新模式.
- 为新请求固定访问码, 浏览器身份和点值版本. 旧报价需用户重新确认, 已受理请求和明确未执行的任务恢复沿用原点值. 更换访问码后不静默转移未完成请求或扣除新码.
- 在服务端事务中预占整批点数, 余额不足整批拒绝. 成功取得可用结果时扣除, 明确失败或执行前取消返还; 下载, 删除作品或临时结果过期不改变成功任务的扣点.
- 为图片和文字保持稳定请求编号及结果复用. 响应丢失后复用原请求, 刷新或重复点击不得重复扣点. 对上游超时, 网络中断或在途重启保留预占并待核实, 不自动重新调用.
- 点击后台访问码卡片打开设置弹窗, 集中修改访问名称, 加减点, 启停, 重置和删除. 将无限额度开关放在点数输入右侧, 开启后禁用数字输入, 切回有限时保留尚未提交的输入. 使用卡片用量图标打开独立的分页流水与待核实弹窗. 对调整和核实保留原因与幂等记录; 重置保留内部 ID 和原账本.
- 对删除和重置只提供影响说明与一次确认, 移除原因输入, 由服务端自动记录操作说明. 仅在同一访问码的设置已被其他页面更新时显示刷新数据, 平时隐藏; 刷新保留用户已修改字段, 未修改字段跟随最新记录, 不自动执行保存/重置/删除. 刷新失败保留重试入口, 普通网络错误重试沿用原请求编号, 避免重复加点或重置.
- 删除访问码后使旧码失效, 从列表移除并取消未执行任务, 保留流水与原浏览器结果领取, 不提供恢复入口. 有运行中或待核实任务时先处理再删除, 避免隐藏未结清记录.
- 对停用或重置码取消尚未执行任务并释放预占, 已开始任务正常收尾, 原浏览器仍可领取结果. 保留管理会话过期后的表单输入.
- 在顶栏显示可用点数或无限灵感点, 对有限额度的图片/文字操作使用统一浅色圆角扣点标记, 按实际点值与数量显示如 `-10点`, `-1点`. 无限额度隐藏按钮内标记, 不显示不限量或无限图标; 旧任务继续按自身模式与点值展示. 移除单独的预计消耗行与生成按钮快捷键文案, 保留预占, 扣除, 返还和待核实状态.
- 有限额度余额为零时仍可登录, 浏览风格, 复制模板与下载本地作品. 不新增支付, 会员, IP 历史或设备指纹. 点数不足时保留提示词, 草稿, 参考图和蒙版.
- 保留旧任务且不追溯扣点. 只通过可信旧会话接续归属, 不自动给旧使用者发放无限额度. 按 [改造清单](ACCESS_CODE_CREDITS_PLAN.md) 与 [部署指南](DEPLOY.md) 完成迁移和验收.

## 8. 验收要求

- 验证四页在桌面/平板/手机和深浅主题下的布局, 同时检查文档溢出和关键按钮边界.
- 验证润色撤销/恢复保留手工修改, 刷新和旧指令请求恢复不重复计费, 本地保存失败与跨标签页冲突保护; 验证空区原生图片粘贴, 已有参考图/蒙版不覆盖, 单层焦点轮廓与减少动态效果.
- 验证多任务, 蒙版透明语义, 真实文件格式, 原子领取, 删除后刷新, 配方恢复, 旧数据迁移和存储失败恢复.

- 验证管理员鉴权隔离, 图片上传/拖拽/真实粘贴, 原文复制/发送, 保存失败保留输入, 版本冲突和会话过期恢复.

- 验证同码共享与浏览器权限隔离, 图片/文字幂等, 原子预占, 失败返还, 手工核实, 调价, 数据库写失败恢复以及 Docker 账本备份恢复.
