# 芽绘台设计规范

生效日期: 2026-09-08. 使用 `stitch_sproutcanvas_studio 2/` 内五份正式稿作为视觉基准. 以用户最新决策修订功能, 不恢复已删除或未经验证的入口.

## 1. 视觉与构建规则

- 保留暖纸白, 植物绿, 分层纸面, 中等圆角和柔和投影.
- 保留原稿布局, 字体层级, 图片裁切, 主要间距和操作顺序. 不套用另一套设计系统.
- 使用 Tailwind 3.4 + PostCSS 编译 `index.html` 和 React 源码. 不使用浏览器 Tailwind CDN, 不依赖设计稿目录参与生产构建.
- 在 `src/styles/stitch.css` 维护 Tailwind 入口, 在 `tokens.css` 维护语义色, 在 `fonts.css` 维护本地字体, 在 `workspace.css` 维护响应式/弹层约束.
- 使用 `html.dark` 切换暗色语义色, 默认浅色, 保存用户主题选择.
- 在本地和 Docker 构建中使用相同输入, 验证 CSS/JS 文件哈希一致.

## 2. 语义色

使用 `rgb(var(--sc-角色) / <alpha-value>)` 接入 Tailwind, 修改时同步亮/暗两套值. 完整表以 `src/styles/tokens.css` 为准, 不再使用历史 `--bg`/`--accent` 映射表作为当前样式定义.

| 角色 | 浅色 | 暗色 | 用途 |
|---|---|---|---|
| surface | #FAF9F5 | #171B16 | 全局纸面 |
| surface-container-lowest | #FFFFFF | #20241E | 内容卡片 |
| surface-container-low | #F4F4F0 | #1C211C | 输入井, 次级面板 |
| surface-container | #EFEEEA | #232823 | 分段轨道, 工具底 |
| surface-container-high | #E9E8E4 | #2A302A | 选中面板 |
| on-surface | #1B1C1A | #E8EBE3 | 正文与标题 |
| on-surface-variant | #44483E | #BFC5B6 | 次要文字 |
| primary | #415B2F | #839E6C | 主操作 |
| primary-container | #597445 | #597445 | 品牌强调表面 |
| outline | #74796D | #8A9280 | 说明和轮廓 |
| outline-variant | #C4C8BB | #39413A | 分隔线 |
| error | #BA1A1A | #F2A8A8 | 错误信息 |

- 成对使用 `primary/on-primary`, `secondary-container/on-secondary-container`, `error-container/on-error-container`.
- 检查正文和背景对比度, 不为匹配静态颜色牺牲可读性.
- 新增状态色时复用语义角色, 不在页面内复制另一套颜色变量.

## 3. 字体与图标

| 用途 | 字体与要求 |
|---|---|
| 标题 | Outfit, 本地 WOFF2, 18/24/32px 层级 |
| 正文 | Inter, 本地 WOFF2, 12/14/16px 层级 |
| 元信息 | JetBrains Mono, 本地 WOFF2, 10/12px 层级 |
| 中文 | 沿用各页面相同的系统中文字体回退; 不为展馆单独覆盖宋体, 按统一标题/正文/元信息层级设置字号与字重 |
| 图标 | 自托管 Material Symbols Outlined, 通过 `StitchIcon` 使用 |

- 保留字体和图标许可, 不依赖运行时外链字体.
- 更新图标子集时保留已有字形与变量轴, 覆盖全屏退出和图片错误状态, 同步更新字体资源版本以清除旧缓存.
- 为纯图标操作提供中文 aria-label 或 title, 不让字体连字成为按钮名称.
- 不用静态图片代替真实文本或可交互控件.

## 4. 间距, 圆角与动效

- 使用 4/8/12/16/24/32/48px 的空间等级. 桌面画布边距 24px.
- 保持 `rounded-lg=8px`, `rounded-xl=12px`, `rounded-2xl=16px`, 胶囊圆角 9999px 的当前 Tailwind 定义.
- 使用原稿绿灰投影和低透明度边框, 区分纸面层级.
- 控件变化使用约 150-200ms, 抽屉/弹层使用约 200-300ms, 避免不必要的持续动画.
- 尊重 `prefers-reduced-motion`, 将过渡时间设为 0, 避免主题色逐层延迟和图片缩放插值; 保留明显的键盘焦点.

## 5. 页面骨架

| 区域 | 布局约束 |
|---|---|
| 共用顶栏 | 固定 64px, 品牌/四页导航/真实状态/队列/主题/退出 |
| 手机顶栏 | 追加 52px 第二行导航, 品牌简写为芽绘台, 队列使用图标和计数, 保留可访问名称 |
| 单图创作 | 桌面 440px 控制栏 + 24px 间隔 + 结果流, 小于 1024px 堆叠为单列 |
| 系列策划 | 上方 7:5 配置区, 下方分镜 1/2/4 列, 时间轴可横向滚动 |
| 风格库 | 搜索/分类固定层, 默认 1/2/3 列卡片, 紧凑模式最多 4 列; 复用顶栏/字体并提供独立管理入口 |
| 风格管理 | 使用同一语义色和字体; 紧凑素材卡与添加/编辑弹窗, 桌面图片和表单两栏, 手机纵向滚动 |
| 展馆 | 使用与风格库相同的素色背景, 24px 画布边距和标题层级; 保留日期分组, 4:3 作品卡与系列叠层 |
| 查看器 | 使用接近全视口的大图工作区, 固定顶栏/图片工具栏, 可收起的 320px 配方栏, 紧凑分镜轨道; 手机优先显示图片, 点击详情后切换到信息面板 |
| 队列抽屉 | 桌面宽 352px, 手机不超过视口, 起点避开固定导航 |
| 蒙版编辑 | 画布与原图等比, 工具和保存动作固定可见, 明确标识涂抹区域 |

- 使用 640/768/1024/1280px 断点, 按内容检查中间宽度.
- 检查主要按钮的 bounding box, 不能只通过 document.scrollWidth 判断没有溢出.
- 在草稿恢复时显示加载状态, 恢复完成后再接受编辑.
- 将刷新恢复限定到未完成草稿. 全部关联图片成功保存后结束草稿, 下次进入显示空白文案与参考区, 保留常用设置和展馆作品. 当前页面继续展示输入与结果; 用户在生成期间修改的内容继续保留, 不受旧任务完成影响.
- 对空数据, 失败, 本地存储受限和会话过期提供真实状态.
- 将失败画稿与后续重试视为同一处占位, 新任务确认入队后收起旧失败卡. 重试提交期间显示正在提交并禁用操作, 提交失败保留原卡; 在队列历史中标识已重新提交, 不再提供旧任务重试入口. 使用生成未完成作为通用失败标题, 不将通道或网络错误一律归因为提示词.

## 6. 交互和文案

- 保持生成, 下载, 复用, 删除等动作名称具体可辨. 等待持久化完成后再提示成功.
- 在单图提示词标题行提供新建创作, 清空文案, 参考图和蒙版并退出局部编辑; 与系列页的新建系列保持一致, 均保留常用生成设置. 手机标题行允许换行, 不挤压操作按钮.
- 使用真实作品数, 风格数, 时间, 尺寸和队列位次, 不注入示例作品填充用户展馆.
- 将风格与分类计数绑定到服务端已上架目录, 初始导入 36 款/6 类, 后续按实际录入数量展示. 卡片展示作者, 详情展示来源与素材许可. 预览, 详情, 复制和发送单图使用同一份提示词原文, 保留换行, 不自动翻译.
- 发送单图后展示已载入模板名称, 提示载入成功, 允许修改后再绘制; 退出旧局部编辑并清除参考图和蒙版, 不追加隐藏描述. 取消发送系列入口.
- 将管理页的图片与提示词作为主要录入项, 作者可留空; 将名称, 分类, 来源链接和排序收在可选信息. 不新增标签, 英文名和画风描述.
- 同时支持选择图片, 拖拽和 Cmd/Ctrl + V 粘贴, 保持文本粘贴正常. 保存期间禁用表单, 失败或会话过期后保留当前输入, 重新登录后继续.
- 在导入前显示新增/更新/相同数量, 经确认后合并, 保留备份外条目. 删除明确提示永久删除和示例图清理.
- 移除作品精选/收藏, 回收站, Seed/CFG/步数/权重控件, 排序项和无意义参数占位.
- 保持系列故事梗概 / 分段分镜剧本为唯一主文本入口, 将主体要求写入其中. 不增加独立主体设定字段, 在系列主体参考区提供可选图片. 不展示风格库选择器, 将画面要求写入梗概.
- 将系列拆解与生图分为两个独立按钮: 上方智能拆解分镜只生成文字, 分镜下方确认并生成按钮显示图片数量. 在待确认卡片中突出可编辑提示词, 缩小空图片占位; 保留草稿和逐镜参数编辑, 刷新不得自动生图.
- 将系列快捷键仅绑定在梗概输入框, 只触发拆解. 重新拆解前确认覆盖旧提示词, 失败时保留当前草稿.
- 保留参考图和配方的实际信息. 旧作品缺少记录时说明未记录, 不编造生成参数.
- 固定展示三种调性选项, 使用不额外调整替代原始配方, 不随参考图或选择状态增删选项. 将单一生成格式渲染为带说明的固定值, 仅在有多种可用格式时展示切换按钮.
- 按查看区尺寸等比适应原图, 移除装饰性相框和固定 vh 图片上限. 将图片变换限制在原图元素, 不让下载/全屏/缩放按钮参与缩放.
- 提供适应窗口, 100% 原始大小, 连续缩放, 鼠标滚轮定位缩放, 拖动和平板/手机双指缩放. 将拖动范围限制在图片边缘, 避免将图片移出查看区.
- 让全屏覆盖完整查看器, 保持工具栏和退出按钮可用; 在适应模式下随视口或详情栏变化自动调整图片, 切换作品/分镜/版本时重置查看位置.
- 为已载入图片提供参考图生成/局部重绘两种明确模式. 局部重绘显示修改要求和只读原参数, 隐藏画风与调性选择; 显式切换参考图后允许调整参数.
- 从作品卡, 查看器或系列进入编辑时使用相同的配方继承逻辑. 显示原 16:9 等画幅和真实目标尺寸, 禁止写死默认 1:1.
- 将已圈定蒙版, 未圈定区域, 保存成功与开始局部重绘区分为独立状态. 清空蒙版不得触发整图生成.
- 将切图放入结果卡的工具菜单. 使用合并帮助页替代未维护的生态更新/个人资料入口.
- 分享入口调用系统文件分享, 不显示不存在的公开链接或云端同步承诺.
- 将真实通道状态区分为未验证, 可用, 最近失败和冷却, 不将应用连通描述为所有上游健康.
- 显示真实已用时间/队列位次, 不显示模拟百分比或准确剩余秒数.
- 将目标画幅与实际文件尺寸分开表达, 不把质量 high 描述为必然的特定分辨率.

## 7. 可访问性与验证

- 为输入, 图标操作, 对话框提供可访问名称; 在模态弹层内限制焦点, Escape 关闭并恢复焦点.
- 保留选中/禁用/加载状态, 使用 aria-pressed/aria-current 表达语义.
- 检查 1600x1000, 1024x900, 390x844 三种视口与深浅主题, 检查四页和关键弹层.
- 检查图片载入, 原图查看/下载, 蒙版尺寸, ZIP, 手机退出和持久化错误提示.
- 检查管理登录, 上传/粘贴/拖拽, 编辑/上下架/删除/备份恢复, 深浅主题, 弹窗滚动与本地图标字形.
- 运行 `npm test` 和 `npm run test:browser`; 容器发布前运行 `npm run test:docker`.
- 按 [UI 对齐记录](UI_STITCH_ALIGNMENT.md) 区分视觉验收与模型效果验收. 不使用逐像素零差异或未经验证的完成百分比.

## 8. 变更约束

- 在修改视觉前核对正式稿与当前功能清单, 保持公共组件一致.
- 修改数据展示时同步真实计算来源和空态, 不写固定样例数量.
- 修改模型参数时同步能力校验, 页面文案与真实验证报告.
- 将新增素材及其许可保存在本地, 不在应用运行时依赖临时外链图片.

## 9. Stitch 移植规则

### 9.0 原稿构建与验收

- 将 `stitch_sproutcanvas_studio 2/` 仅作为设计参照, 不将其 HTML 当作生产应用入口.
- 将原稿原子类转入 React 组件并通过 Tailwind 编译, 不手工截取不完整 CDN CSS.
- 复用 `components/shell/`, `components/gallery/`, `components/series/` 和 `components/ui/` 的公共控件.
- 动态数据和用户决定删除的功能允许相应变化; 其他布局和视觉语言继续按正式稿维护.
- 为本轮功能与架构变动保留 F01-F17, B01-B08, A01-A10 编号, 统一在 [功能清单](FEATURE_ARCHITECTURE_REVIEW.md) 跟踪.
