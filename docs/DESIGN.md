# 芽绘台设计规范

生效日期: 2026-09-13. 使用 `stitch_sproutcanvas_studio 2/` 内五份正式稿作为视觉基准. 以用户最新决策修订功能, 不恢复已删除或未经验证的入口.

## 1. 视觉与构建规则

- 保留暖纸白, 植物绿, 分层纸面, 中等圆角和柔和投影.
- 保留原稿布局, 字体层级, 图片裁切, 主要间距和操作顺序. 不套用另一套设计系统.
- 使用 Tailwind 3.4 + PostCSS 编译 `index.html` 和 React 源码. 不使用浏览器 Tailwind CDN, 不依赖设计稿目录参与生产构建.
- 在 `src/styles/stitch.css` 维护 Tailwind 入口, 在 `tokens.css` 维护语义色, 在 `fonts.css` 维护本地字体, 在 `workspace.css` 维护工作台响应式/弹层约束, 在 `admin.css` 维护后台外壳, 在 `auth.css` 维护共用登录布局.
- 使用 `html.dark` 切换暗色语义色, 默认浅色, 保存用户主题选择.
- 在本地和 Docker 构建中使用相同输入, 验证 CSS/JS 文件哈希一致.

## 2. 语义色

使用 `rgb(var(--sc-角色) / <alpha-value>)` 接入 Tailwind, 修改时同步亮/暗两套值. 完整表以 `src/styles/tokens.css` 为准, 不再使用历史 `--bg`/`--accent` 映射表作为当前样式定义.

| 角色 | 浅色 | 暗色 | 用途 |
|---|---|---|---|
| surface | #FAF9F5 | #171B16 | 全局纸面 |
| surface-container-lowest | #FFFFFF | #20241E | 内容卡片 |
| surface-container-low | #F4F4F0 | #1C211C | 输入井, 次级面板 |
| surface-container | #EFEEEA | #232823 | 分段轨道, 工具底 |
| surface-container-high | #E9E8E4 | #2A302A | 选中面板 |
| on-surface | #1B1C1A | #E8EBE3 | 正文与标题 |
| on-surface-variant | #44483E | #BFC5B6 | 次要文字 |
| primary | #415B2F | #839E6C | 主操作 |
| primary-container | #597445 | #597445 | 品牌强调表面 |
| outline | #74796D | #8A9280 | 说明和轮廓 |
| outline-variant | #C4C8BB | #39413A | 分隔线 |
| error | #BA1A1A | #F2A8A8 | 错误信息 |

- 成对使用 `primary/on-primary`, `secondary-container/on-secondary-container`, `error-container/on-error-container`.
- 检查正文和背景对比度, 不为匹配静态颜色牺牲可读性.
- 新增状态色时复用语义角色, 不在页面内复制另一套颜色变量.

## 3. 字体与图标

| 用途 | 字体与要求 |
|---|---|
| 标题 | Outfit, 本地 WOFF2, 18/24/32px 层级 |
| 正文 | Inter, 本地 WOFF2, 12/14/16px 层级 |
| 元信息 | JetBrains Mono, 本地 WOFF2, 10/12px 层级 |
| 中文 | 沿用各页面相同的系统中文字体回退; 不为展馆单独覆盖宋体, 按统一标题/正文/元信息层级设置字号与字重 |
| 图标 | 自托管 Material Symbols Outlined, 通过 `StitchIcon` 使用 |

- 保留字体和图标许可, 不依赖运行时外链字体.
- 更新图标子集时保留已有字形与变量轴, 覆盖全屏退出和图片错误状态, 同步更新字体资源版本以清除旧缓存.
- 为纯图标操作提供中文 aria-label 或 title, 不让字体连字成为按钮名称.
- 不用静态图片代替真实文本或可交互控件.

## 4. 间距, 圆角与动效

- 使用 4/8/12/16/24/32/48px 的空间等级. 桌面画布边距 24px.
- 保持 `rounded-lg=8px`, `rounded-xl=12px`, `rounded-2xl=16px`, 胶囊圆角 9999px 的当前 Tailwind 定义.
- 使用原稿绿灰投影和低透明度边框, 区分纸面层级.
- 控件变化使用约 150-200ms, 抽屉/弹层使用约 200-300ms, 避免不必要的持续动画.
- 仅在提示词润色期间显示沿外边框移动的植物绿流光, 使用 3 秒旋转周期, 不闪烁且不改变布局尺寸. 将动画隔离在轻量组件内, 仅变换 transform; 减少动态效果时保留静态描边.
- 尊重 `prefers-reduced-motion`, 将过渡时间设为 0, 避免主题色逐层延迟和图片缩放插值; 保留明显的键盘焦点.

## 5. 页面骨架

| 区域 | 布局约束 |
|---|---|
| 共用顶栏 | 固定 64px, 80% 纸面底色与 24px 背景模糊; 品牌/四页导航/加粗灵感点/队列/用户入口; 将名称, 外观, 帮助和退出收进用户浮窗, 不展示通道状态 |
| 手机顶栏 | 追加 52px 第二行导航, 品牌简写为芽绘台, 队列使用图标和计数, 保留可访问名称 |
| 单图创作 | 桌面 440px 控制栏 + 24px 间隔 + 最近 4 个创作记录, 两栏随整页滚动, 配置栏不吸顶; 小于 1024px 堆叠为单列 |
| 系列策划 | 上方 7:5 配置区, 下方分镜 1/2/4 列, 时间轴可横向滚动 |
| 风格库 | 搜索/分类固定层, 分类单行可横滑. 默认手机 1 列、平板 2 列、电脑 3 列; 紧凑模式手机 2 列、电脑最多 4 列. 复用顶栏/字体, 不展示管理入口 |
| 工作台/管理登录 | 复用 64px 品牌顶栏, 纸面底色与共用表单; 桌面采用最大 1040px 的介绍/登录双栏, 小于 1024px 收起介绍区, 表单最大 440px; 使用相同字体, 16px 卡片圆角, 单层输入焦点轮廓, 密码显隐与主题切换, 管理入口额外提供返回工作台 |
| 管理后台 | 保持独立入口; 复用前台顶栏的品牌和分段导航, 提供仪表盘/风格管理/访问码管理三个入口; 桌面 64px 顶栏, 小于 1024px 将导航放在第二行, 内容最大宽度 1440px |
| 仪表盘 | 使用 2/4 列真实统计, 365 天活跃度热力图, 创作使用/待核实和最近风格; 在用量与创作卡片内独立切换今日/本月/累计, 直达编辑或独立核实弹窗 |
| 风格管理 | 使用统一页标题和搜索栏, 素材卡片 1/2/3/4 列, 上图下文; 整卡进入编辑, 独立上下架/删除; 弹窗桌面左侧图片, 右侧展开全部字段, 手机纵向滚动并固定保存区 |
| 访问码管理 | 使用紧凑双点值设置区和搜索筛选, 下方 1/2/4 列额度卡; 创建/调整/重置与分页明细使用适应视口的统一圆角弹窗 |
| 展馆 | 使用与风格库相同的素色背景, 24px 画布边距和标题层级; 保留日期分组, 4:3 作品卡与系列叠层. 点封面打开详情, 选择模式才显示勾选和批量操作. 类型/画幅/排序平铺筛选, 去掉页内跳转 |
| 查看器 | 电脑固定约 80vw、上限 64rem 的居中弹窗, 手机留边不铺满; 固定顶栏/图片工具栏, 可收起的 320px 配方栏, 紧凑分镜轨道. 手机优先显示图片, 点击详情后切换到信息面板. 长提示词在栏内滚动, 操作按钮固定在栏底 |
| 队列抽屉 | 桌面宽 352px, 手机不超过视口, 起点避开固定导航 |
| 蒙版编辑 | 画布与原图等比, 工具和保存动作固定可见, 明确标识涂抹区域 |

- 使用 640/768/1024/1280px 断点, 按内容检查中间宽度.
- 检查主要按钮的 bounding box, 不能只通过 document.scrollWidth 判断没有溢出.
- 在草稿恢复时显示加载状态, 恢复完成后再接受编辑.
- 将刷新恢复限定到未完成草稿. 全部关联图片成功保存后结束草稿, 下次进入显示空白文案与参考区, 保留常用设置和展馆作品. 当前页面继续展示输入与结果; 用户在生成期间修改的内容继续保留, 不受旧任务完成影响.
- 对空数据, 失败, 本地存储受限和会话过期提供真实状态.
- 将失败画稿与后续重试视为同一处占位, 新任务确认入队后收起旧失败卡. 重试提交期间显示正在提交并禁用操作, 提交失败保留原卡; 在队列历史中标识已重新提交, 不再提供旧任务重试入口. 使用生成未完成作为通用失败标题, 不将通道或网络错误一律归因为提示词.

## 6. 交互和文案

- 登录保持单个访问码输入框, 支持粘贴与显隐, 显示可见标签和真实服务端错误, 将错误关联到输入框. 登录期间禁用输入, 显隐和重复提交; 在共用登录布局内展示初始连接, 连接失败重试与管理入口未配置状态. 不增加用户名, 注册或过期日期控件, 不在工作台登录页展示管理入口.
- 使用紧凑植物绿徽标展示可用灵感点, 无限额度只在顶栏显示无限灵感点, 有原额度占用时显示第二行说明. 对有限额度的绘图, 润色, 拆解, 系列确认及单镜/重试按钮使用浅色圆角点数标记, 如 `-10点` 与 `-1点`; 按后台点值与实际数量更新. 无限操作隐藏按钮内点数标记, 不显示不限量文字或额外图标; 历史任务按自身模式展示. 移除生成区独立预计行与按钮快捷键文案, 保留快捷键能力与帮助说明. 额度不足时保留输入.
- 加粗顶栏的灵感点文字与数字. 用户浮窗使用约 288px 宽的圆角纸面, 右侧对齐并适配窄屏; 显示访问名称与脱敏尾号, 中部提供浅色/深色分段按钮及使用帮助, 底部用分隔线收纳退出. 支持点击开启, 外部点击, Esc 和键盘移出关闭, 不依赖悬停.
- 将访问码备注字段标为访问名称(用户可见), 同码显示相同名称, 空值显示创作者. 在帮助中说明共享额度, 成功扣除/明确失败返还/未知结果待核实和本地保存规则, 不显示通道健康详情.
- 以最多 4 个卡片位置展示最近创作, 优先当前批次, 再保留其他未完成任务, 不足时补最近作品. 从任务到本地保存的各阶段保持同一位置, 连续提交时不得用后一批覆盖仍在生成的前一张. 保留失败反馈和手动重试. 使用前往展馆替代全部画稿/今日作品筛选, 完整历史保留在展馆和队列.
- 对上传和提交待确认使用普通等待卡, 不显示生成失败或开放上传中的重试/取消. 在单图, 系列与队列中分别展示下载原图, 保存作品和确认领取; 对领取错误提供重试领取, 不显示生成扣点标记, 不把尚未保存的分镜恢复为待生成.
- 将全站生图状态区集中在我的任务抽屉顶部, 用生成中/等待中的数字徽标展示全站负载, 明确包含自己的等待项与创作者轮流规则. 单图画卷与系列看板仅保留个人任务状态, 顺序和耗时, 不重复展示全站统计. 将个人任务标为我的待生成第 N 张, 不使用含糊的第 N 位或虚构全站名次. 状态同步失败时标记上次状态, 不把读取失败显示为空闲.
- 让排队与渲染分别显示真实已用时, 使用等宽数字并由前端每秒推进, 保留服务端每 2 秒同步状态. 不显示虚构百分比或预计完成倒计时. 从排队进入渲染后重置为渲染耗时, 后台页暂停刷新并在返回时校正, 不每秒触发读屏播报.
- 在画卷与我的任务中移除固定比例进度条, 用静态时钟表示排队或等待领取, 用轻量旋转图标表示提交, 渲染和实际领取. 错误时停止动画并显示错误图标, 保留领取重试; 遵守减少动态效果设置, 不通过活动动画暗示完成比例.
- 使用已预占, 已扣除, 已返还, 待核实与结算待同步区分任务状态. 不把点数占用当成重复扣除, 不增加充值入口.
- 访问码卡片展示尾号, 访问名称, 状态, 额度, 累计用量与最近使用时间; 点击整卡或键盘激活后打开设置弹窗, 卡片用量图标打开独立明细弹窗, 不互相触发. 将访问名称, 加减点和启停集中保存, 点数输入右侧提供无限额度开关, 开启后禁用数字输入, 切回有限保留输入; 将重置和删除放在设置弹窗操作区.
- 完整码只在创建/重置成功弹窗中供复制. 删除前在原弹窗内确认, 说明不可恢复; 执行中或待核实任务未结束时保留入口并提示处理. 加减点和核实不展示原因输入, 由服务端自动记录; 无限任务流水标注等值用量与不扣点状态.
- 将访问码删除/重置确认区简化为影响说明, 取消和确认按钮, 移除原因输入, 自动保存操作记录. 从常态编辑弹窗移除载入最新版本, 仅在版本冲突提示旁展示刷新数据. 刷新时保留已编辑内容并更新其余字段, 完成后隐藏刷新按钮, 等待再次确认; 刷新失败仍可重试, 不将普通网络错误当作版本冲突.
- 在后台保存失败或会话过期后保留输入. 重读点值或版本时允许用户核对后保存, 首次读取失败提供原地重试入口.
- 让仪表盘统计只读取服务端数据, 按已结算操作区分实际扣减和无限额度等值用量; 未确认结果单列待核实, 不计入已完成用量. 刷新失败时保留并标记旧数据, 未登录时隐藏所有统计.
- 在灵感点用量与创作使用卡片内使用今日/本月/累计分段按钮, 默认本月. 不对风格库存, 访问码启停和待核实快照添加时段切换. 用植物绿深浅展示最近 365 天每天已结算的创作次数, 空日期保持零值; 明确北京时间与结算日期口径, 支持悬停, 点击和键盘查看, 手机只在热力图区横向滚动并定位最近日期.
- 保持生成, 下载, 复用, 删除等动作名称具体可辨. 等待持久化完成后再提示成功.
- 在单图提示词标题行提供新建创作, 清空文案, 参考图和蒙版并退出局部编辑; 与系列页的新建系列保持一致, 均保留常用生成设置. 手机标题行允许换行, 不挤压操作按钮.
- 将提示词和底部工具栏放在同一圆角输入容器, 聚焦时只显示外层轮廓, 移除 textarea 内层描边. 在工具栏提供撤销润色/恢复润色, 不显示扣点标记. 两侧手工修改与最近一次润色前后版本随草稿保存, 刷新可继续切换; 新建, 模板/配方切换和草稿完成时清理旧记录.
- 润色期间保持原文可读且只读, 禁用清空, 重复润色和生成, 显示边框流光和处理中状态. 成功后开放编辑与撤销, 失败恢复原状态并保留原文; 不增加结果弹窗. 在帮助中说明撤销/恢复免费, 不撤回已成功调用的费用.
- 在参考区提示上传, 拖拽与 Cmd/Ctrl + V 粘贴追加, 有空位时按顺序载入, 不覆盖已有素材. 使用更换按钮显式替换, 超量时拒绝整批并提示剩余容量. 不要求先聚焦提示词, 保留普通文字粘贴; 在读取期间防止重复输入, 在局部重绘与预览弹窗中阻止追加. 保留风格库入口, 不恢复基础画风快捷项.
- 在单图参考模式与系列共用四个横向方形槽位, 空态和载入图片后保持同一行及固定行高, 不因第 3/4 张图出现第二行. 按顺序标注图 1 至图 4, 空位点击多选添加, 缩略图完整显示图片比例, 更换/移除按钮独立于预览入口. 在窄屏缩小槽位, 必要时纵向排列槽位下的操作按钮, 保留触控尺寸并同时显示四槽. 显示数量与上限, 保留清空全部; 文件名放在悬停提示和大图预览中.
- 通过顶部入口切换参考图生成与局部重绘, 不自动打开弹窗. 切换到局部重绘时固定使用第一张参考图, 以紧凑的单图卡片展示原图缩略图, 文件名, 更换图片和绘制/编辑蒙版按钮, 不展示多图槽位或选择器. 只预览当前编辑原图, 用简短提示说明其余图片已保留; 切回参考模式后恢复完整列表和追加入口. 取消蒙版编辑时保留进入弹窗前的草稿, 未保存蒙版前阻止生成. 沿用单份创作草稿, 不增加双模式独立草稿.
- 使用真实作品数, 风格数, 时间, 尺寸和队列位次, 不注入示例作品填充用户展馆.
- 将风格与分类计数绑定到服务端已上架目录, 初始导入 36 款/6 类, 后续按实际录入数量展示. 卡片展示作者, 详情展示来源与素材许可. 预览, 详情, 复制和发送单图使用同一份提示词原文, 保留换行, 不自动翻译.
- 发送单图后在提示词下方展示紧凑模板卡片, 仅展示示例图和名称, 替换标题旁旧风格标签. 提供更换模板和移除关联, 移除后保留当前文案; 不展示作者, 分类或底部常驻说明, 在风格库保留作者署名. 提示载入成功, 允许修改后再绘制; 退出旧局部编辑并清除参考图和蒙版, 不追加隐藏描述. 取消发送系列入口.
