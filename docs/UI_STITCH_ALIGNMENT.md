# Stitch UI 对齐与验收记录

更新日期: 2026-09-07. 以 `stitch_sproutcanvas_studio 2/` 的五份正式 code.html/screen.png 为视觉基准, 以用户最新决定修订功能. 完整编号清单见 [功能整改与架构评估](FEATURE_ARCHITECTURE_REVIEW.md).

## 1. 保持的视觉范围

- 保留纸面色阶, 植物绿, Outfit / Inter / JetBrains Mono, 本地 Material Symbols, 间距与圆角. 统一展馆标题字体与前几页, 取消独立宋体和背景光斑.
- 保留四页导航, 单图控制栏与结果流, 系列设定台与分镜矩阵, 风格图文卡与展馆叠层卡. 按用户要求将详情改为大图查看器, 取消装饰相框.
- 使用真实作品, 任务, 风格数量和文件尺寸. 不向用户 IndexedDB 注入示例作品制造截图一致.
- 将桌面和手机行为分别验收, 不用文档无横向滚动替代实际按钮可点击性.
- 不以本轮截图声称逐像素零差异; 动态数据, 参数能力和明确删除项以真实行为为准.

- 在单图/系列草稿恢复完成前显示加载状态, 防止默认值或旧草稿覆盖新输入.
